     4→
     5→A single-route Next.js 16 App Router implementation of the FRONTEND.md spec
     6→(AI-Powered Multilingual Citizen Grievance Platform). Built frontend-only
     7→with an in-memory mock API layer that follows the `{ success, data, error }`

    13→  react-hook-form + zod, recharts, next-themes, sonner, lucide-react.
